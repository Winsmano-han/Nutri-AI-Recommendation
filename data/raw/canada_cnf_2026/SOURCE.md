# Canada CNF 2026 Raw Dataset

Source: Health Canada Canadian Nutrient File (CNF) API.

The CNF is the standard reference food composition database for foods commonly consumed in Canada. The API provides food descriptions, nutrient names, and nutrient amounts per 100 g edible portion.

Downloaded endpoints:
- https://food-nutrition.canada.ca/api/canadian-nutrient-file/food/?lang=en&type=json
- https://food-nutrition.canada.ca/api/canadian-nutrient-file/nutrientname/?lang=en&type=json
- https://food-nutrition.canada.ca/api/canadian-nutrient-file/nutrientamount/?lang=en&type=json
